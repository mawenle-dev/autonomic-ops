## 二、新增能力

- `ReceiptJournal.verify_chain()`：逐条复算回执哈希与前序链接，返回首个断点。
  `constitution status` 命令可直接查看契约、预算、回执链与反账状态。
- 更新通道：`release/updates/manifest.json` 记录更新包 sha256；发布台提供
  “检查更新”与“暂存更新”，仅校验与暂存，不在运行中替换自身。
  `tools/update_manifest.py` 生成清单并支持 `--check` 复核。
- 版本快照：`tools/snapshot_version.py` 将文档与台账复制到
  `release/snapshots/v<版本>/` 并写入逐文件哈希，不覆盖既有快照。
- 版本规划文档：记录各系列条目分布、补丁数量上限与后续扩展段，避免版本号失衡。

## 五、已知边界

1. 产品仅支持 Linux；Windows 仅运行发布台。
2. 发布依赖 git；Windows 主机未安装 git 时发布会被前置拒绝。
3. `counsel` 为提案 schema 校验器，不是本地推理模型。
4. `versions.yaml` 的 `implemented_local` 表示代码与测试存在于本地，不表示已发布。
5. 104 项验收中仍有契约级检查，不能替代端到端验收。
6. 本轮未推送远端仓库，未创建新标签，未发布新版本。
