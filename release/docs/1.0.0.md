# 1.0.0

- 类型：首个基线版本
- 发布状态：已发布（GitHub Release v1.0.0）

## 本版内容

1. Linux 单机常驻运维代理：采集、检测、规则引擎与有界处置
2. 内容寻址快照、字节级回滚、哈希链审计日志
3. 只读 Web 面板与 Prometheus `/metrics`
4. 白名单、风险分级、人工审批、禁止路径与沙箱约束
5. systemd 部署单元与离线运行模型
